## Descripción de los métodos
- ordenamientoBurbuja: compara elementos vecinos y los intercambia
  cuando el primero es mayor. Realiza todas las pasadas.
- ordenamientoBurbujaMejorado: utiliza una bandera llamada
  huboCambio para detenerse si una pasada termina sin intercambios.

## Organización del programa
La clase MetodosDeOrdenamiento contiene:
- main: crea los arreglos de prueba y muestra su estado inicial y final.
- ordenamientoBurbuja: implementa el algoritmo normal.
- ordenamientoBurbujaMejorado: implementa el algoritmo optimizado.
